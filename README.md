# Pixel Miner — klikací hra

Jednoduchá online klikací hra s obchodem vylepšení.

## Spuštění online

1. V repozitáři otevři **Settings → Pages**.
2. U **Build and deployment** vyber **Deploy from a branch**.
3. Zvol větev `main` a složku `/ (root)`, potom klikni na **Save**.
4. Hra bude dostupná na adrese:
   `https://vojtechtrunecka11-cyber.github.io/klikaci-hra/`

Změny v souborech `index.html`, `style.css` nebo `script.js` se po chvíli automaticky projeví online. Postup hry se ukládá do `localStorage` prohlížeče.
